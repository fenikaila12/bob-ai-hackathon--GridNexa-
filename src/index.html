About

PortFlow AI

PortFlow AI is an academic front-end prototype that demonstrates decision-support tools for port operators to predict congestion hotspots, recommend alternate routes, optimise berth and crane assignments, and generate a 72-hour operations plan.

Problem

Port congestion is often identified too late, causing vessel queues and operational delays.

Solution

A front-end decision-support prototype that visualises vessel schedules, berth capacity, congestion risk, route recommendations, resource allocation and a 72-hour operational plan.

Technology

HTML5 • CSS3 • JavaScript

Important: This project is an academic front-end prototype using simulated operational data.
